# 自定义手镯受阻音效 V0.14.8

- 使用用户提供的 `crystal.wav`，从约 0.295 秒处开始截取 1.8 秒有效碰撞与自然衰减尾音，制作 `public/assets/audio/crystal_block.mp3`（44.1 kHz、单声道、MP3 VBR 高质量）；源文件保留在用户附件，不替换其他游戏音效。
- `Audio.collision()` 的音色由旧 `collision.wav` 改为新素材，不再随机改变播放速度／音高，仍由正常玩法的真实旋转阻挡事件触发，并继续停止旋转音效。
- 同一接触点持续阻挡只播放一次，不同接触点之间设置 150 ms 碰撞声冷却，防止高频拖动导致声音堆叠；手镯恢复移动后的再次受阻依旧能重新触发。
- 保留受阻红光和触觉反馈、音效总开关、后台失焦清理。其它按钮、对齐、解扣、通关和转动音效保持原样。
- 游戏启动时预加载 MP3，平台导出验收增加受阻音频存在性检查。补充音频单元测试以验证路径、原速播放、防重入和预加载。

## 验证范围

需执行 `npm run typecheck` 与 `npm run test:fast`，并在预览库和移动设备手动验证真实受阻、重复拖动、反转重撞和音效开关。提交代码不代表已经完成游戏音频的实机听感验收。
