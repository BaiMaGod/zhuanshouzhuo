# 图片素材体积整改（2026-10-18）

范围：只优化现有运行图片、采样数据和资源打包检查；不改玩法、布局、素材风格或启动加载流程。
基线：main `02dda87f3dd231eac3b41f5a24987043d115734b`。

## 接受条件

- 运行图片总量不超过 3 MiB；高清原图、历史图片不进入运行包。
- 玉盘像素完全保留，玉镯归一化 UV 和玩法网格不变。
- 首页、教学、正式第1关、最大缩放、手指提示、正式第100关在 390×844 和 1280×720 下无明显模糊、白边、颜色变化或纹理偏移。
- 类型检查、相关回归和真实手机触控通过；发布另经现有预览仓库的官方 Laya 3.4 构建与浏览器门禁。

## 结果

| 素材 | 原尺寸 → 运行尺寸 | 原字节数 | 运行字节数 |
|---|---|---:|---:|
| 锁扣 | 2022×778 → 128×49 | 1,177,351 | 9,893 |
| 五种手镯合计 | 各1254×1254 → 各512×512 | 4,621,283 | 912,702 |
| 玉盘 | 1122×1402，保持分辨率及RGBA像素 | 1,664,795 | 1,346,436 |
| 阴影 | 768×768 → 256×256 | 49,894 | 28,641 |
| 手指、首页背景 | 保持现状 | 278,574 | 278,574 |
| **合计** | **10张** | **7,791,897** | **2,576,246** |

总量由 7.43 MiB 降至 2.46 MiB，减少 66.94%。八张调整图片的基础 RGBA 纹理估算从 44.25 MiB 降至 11.27 MiB；这是尺寸估算，不含引擎缓存、图集、mipmap，也不等于真机实测峰值内存。

高清原图保存在 `art-source/`，`scripts/optimize-images.py` 可重复生成运行 PNG 和同步轮廓坐标。
不裁切透明边缘，不改变贴图原点；中心、半径、宽高同比例缩放，测试以 1e-12 容差验证归一化坐标一致。

`scripts/runtime-images.mjs` 统一定义图片清单与预算，普通 Web/H5 构建、Laya 工程准备、官方 Web/小游戏导出均检查实际图片尺寸、总量和额外图片。
Android/iOS 共用经检查的 Laya 输入素材；本次未声称完成原生宿主验收。
