# 旋转吸附与触觉反馈

- 拖动中朝锁扣靠近，缺口进入 7° 范围时自动吸附；松手时也尝试吸附。
- 仅选择实际位于环体上的有效锁扣端点，按距离排序；提前用规则引擎验证路径，不能越过碰撞或绕过活动扣约束。
- 吸附、进入对齐及脱扣时轻震；遇阻时短震，并在正在拖动的手镯内外边缘显示约 550ms 红光，末尾淡出。
- 触觉反馈间隔至少 180ms，避免连续触摸事件重复震动。Web 使用可选 vibration 能力；微信/抖音小游戏使用各自 vibrateShort。平台拒绝或不支持时静默退化。
- 保持原有关卡、通关判定和消除规则；吸附不增加转动步数。

验证：构建通过；吸附、阻挡、触觉节流、红光清理及现有场景和规则共 48 项测试通过；另有平台测试通过。实际震动强度仍需真机体验。
