# V0.5 正式挑战与盘面缩放

用户要求：当前10关保留为教学关，按钮保留；新增超级困难正式关卡，大量手镯，并支持屏幕缩放。

## 关卡

新增正式挑战「九宫锁玉阵」，首页独立开放，不强迫先通过教学关。54只玉镯构成单一连接图，62根锁杆（53根所属杆、9根背景杆），九宫采用三种朝向，其机关由8根跨宫所属杆相连。跨宫杆的所属镯在下一宫中心仍存在时不能合法转动，因此需要判断外围连接、保持两只接收镯的对齐位置并逐步释放中心。最后仍要分别处理背景杆，不存在永久累计解锁或收回锁杆。

已验证路线共63次正常旋转操作，穿过所有实际碰撞检查，全部54镯消除，9根背景杆保留。此路线用于QA和星级基准，不在正式关提供提示、演示、微调或自动对准按钮，也禁止正式关的键盘微调。63次是验证路线长度，不宣称数学最少步数。

原10关的points/links/solutions不变，教学进度和正式挑战成绩独立。正式通关不跳过教学解锁；记录刷新后仍保留。

## 视图与操作

手机：双指缩放与平移，拖空白移动，拖玉镯旋转。点「移动棋盘」可在任何位置拖动画面；点「旋转手镯」返回解镯操作。电脑：滚轮以鼠标位置缩放，也可用＋/−，拖空白或移动模式平移。全盘按钮恢复初始视角。倍率100%至最多800%，按素材清晰度上限3.4世界倍率限制。

缩放只改变显示与命中坐标，不改变环体、缺口、杆件世界几何。双指期间不旋转、不记步、不吸附；抬起一指后，余下一指不会被当作旋转。盘面裁切在托盘区域，移动有边界限制；重开、首页、失焦、取消和弹窗释放指针。撤销恢复规则状态并保留当前视角。

## 性能与验收

远离当前玉镯或运动杆的实体先做保守距离筛选，不改变连续0.25°步进碰撞。环ID查找使用状态对应的缓存，释放判定一次收集所有仍被扣住的环，避免54镯时重复遍历。

接受条件：教学十关回归、54镯图连通/几何合法/跨宫阻挡/全程通关、成绩存储独立；桌面720×1280及手机390×844/375×667实际输入验证双指不误转、缩放后准确旋转、平移、撤销、重开、结算及刷新；发布产物无可修改调试桥。官方LayaAir 3.4构建和浏览器关卡流程全部通过后才发布。
