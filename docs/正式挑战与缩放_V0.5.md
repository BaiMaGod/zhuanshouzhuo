# V0.5.5 正式挑战与盘面缩放

## 已实现内容

保留现有10关作为教学关，原有微调、30°转动、提示、对准一扣和演示等按钮继续保留。首页另设「挑战九宫锁玉阵」，无需先完成教学关即可进入正式挑战。

正式关共54只玉镯、62根锁杆（53根所属杆和9根背景杆），九宫采用三种朝向，以8根跨宫所属杆连成同一个连接图。跨宫杆阻止提前转动，需要判断外围、保持组合以及释放中心的顺序。保持已确认的规则：对齐后转离会重新扣合，所属杆只随所属镯消失，背景杆保留，不能把对齐变成永久解锁或收回杆件。

正式关不提供微调、30°转动、提示、自动对准和演示按钮，键盘微调也不可用。采用真实拖动旋转，提供撤销、重开、音效、玩法和视图操作。教学进度与正式关最好成绩独立保存，正式通关不会跳过教学解锁。

## 缩放和视图

手机双指缩放和平移；电脑滚轮以指针位置缩放。支持＋/−、全盘复位、拖动空白平移及「移动棋盘」模式。倍率100%至最多800%，受世界显示倍率3.4的清晰度上限约束。

双指手势不转动、不计步、不吸附；抬起一指后，余下一指不会误转手镯。盘面裁切在视图区域，并限制平移边界。重开恢复全盘，撤销恢复实际状态并保留当前缩放与视角，弹窗、失焦和取消释放指针。

静止游戏场景按显示分辨率缓存；视图或状态变化重新绘制。放大和平移后剔除屏幕外的环体、阴影与锁杆绘制，完整世界状态和碰撞计算继续保留。连续旋转仍以0.25°步进检查，远处实体先保守筛选，释放判定与环ID查找减少重复计算。玉镯与场景素材保持原样。
