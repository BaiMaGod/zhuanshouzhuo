# 《转手镯消除》玩法设计文档

## 1. 游戏定位

游戏类型：旋转解锁 + 机关拆解 + 消除益智游戏。

核心体验：

- 观察手镯结构
- 寻找缺口方向
- 旋转手镯对准卡扣
- 解开连接关系
- 产生拆解反馈
- 完成连锁消除

目标：制作一款规则简单、反馈爽快、适合移动端休闲玩家的拆解类小游戏。

---

# 2. 核心玩法规则

## 2.1 手镯组成

每个手镯包含：

- 手镯主体
- 缺口（Gap）
- 连接卡扣（Connector）
- 旋转角度
- 当前连接状态

玩家通过旋转手镯，使缺口移动到卡扣位置。

---

# 3. 卡扣系统

## 3.1 固定卡扣

特点：

- 卡扣固定在世界位置
- 手镯旋转不会带动卡扣移动
- 需要玩家调整手镯缺口位置

示例：

```
手镯A
  |
 卡扣
  |
手镯B
```

---

## 3.2 跟随卡扣

特点：

- 卡扣绑定在某个手镯上
- 手镯旋转时卡扣同步旋转
- 增加判断难度

示例：

```
手镯A
 \
  卡扣
```

---

# 4. 消除判定规则

## 4.1 单卡扣

条件：

```
缺口方向 = 卡扣位置
```

满足后：

1. 卡扣解除
2. 手镯脱离
3. 手镯消除

---

## 4.2 多卡扣

一个手镯可能连接多个卡扣。

例如：

```
A
|
卡扣AB
|
B
|
卡扣BC
|
C
```

B 有两个连接：

- AB
- BC

必须满足：

```
AB解除
+
BC解除
```

B 才能消除。

```ts
Bracelet {

 gapAngle:number;
 connectors:string[];
 removed:boolean;
}
```

## Connector

```ts
Connector {
 id:string;
 type:"fixed" | "follow";
 position:{x:number,y:number};
 braceletA:string;
 braceletB:string;
 broken:boolean;
}
```

# 6. 游戏流程

```
进入关卡
 ↓
观察手镯连接关系
 ↓
旋转目标手镯
 ↓
缺口接近卡扣
 ↓
卡扣解除
 ↓
判断是否还有其它连接
 ↓
全部解除
 ↓
手镯消除
 ↓
进入下一层拆解
```

# 7. MVP开发计划

## MVP 0

目标：验证核心操作。

包含：

- 一个手镯
- 一个卡扣
- 旋转操作
- 缺口检测
- 消除反馈

---

## MVP 1

目标：验证连接关系。

包含：

- 两个手镯

- 拆解动画

---

## MVP 2

目标：验证完整玩法。

包含：

- 多手镯

# 8. 关卡设计方向

## 初级关卡

特点：

- 单卡扣
- 明显缺口
- 教学旋转

## 中级关卡

特点：

## 高级关卡

特点：

# 10. 开发原则

核心原则：

> 先保证真实拆解逻辑，再提升美术表现。

所有版本必须优先验证：

- 手镯能旋转
- 卡扣位置正确
- 缺口判定正确
- 消除反馈正确
