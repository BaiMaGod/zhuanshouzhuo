# 画面辨识与渲染优化

## 修改前验收条件

- 保留玉石、玉盘、桃花、手势和音频原素材；保留规则、±10°吸附、计分、音量及平台配置。
- 加强玉镯与玉盘的接触阴影；实际按住手镯时以缺口两端局部亮点和阴影区分操作对象，不增加环形选中描边，不遮挡缺口、不改变位置或碰撞。
- 松手、取消、离开场景、重开后操作强调恢复；减少动态模式不新增闪烁。
- 受阻轮廓只生成一次，逐帧只更新旋转、可见性和透明度；过期后完全隐藏。保留已有红色受阻反馈。
- 消除、清盘、逐星与真实成绩反馈保留；连续重开无残留。高并发按钮/阻挡声不得挤掉消除和通关声；静音、后台暂停、原音量不受损。
- 真实拖动覆盖390×844、360×640、1280×720及减少动态模式；完成第一关、重玩、下一关；查看修改前后同状态截图。
- 运行类型检查、现有单元回归、100关回归。帧间隔目标仍为p95≤33.3ms，不下调预算。无截图采样的同环境前后测量分别记录静止、拖动与受阻场景，不能把浏览器模拟当作实体设备性能。
- 音频事件与暂停恢复可自动验证，实际听音、实体手机和TapTap宿主如无条件必须保持待验。

## 验证记录

实现版本：0.15.12。被测代码提交：`9b4901f578890cc394bfee9f11a6d1cd79b5a14b`，代码树：`93ccb1500a9394723fc9166aaa182d34e782df28`。本文件后续更新仅补充验证记录，不改被测运行代码。

### 已落实

- 复用现有缺口形状阴影增加近距离接触层，使浅玉与浅色玉盘、相邻玉镯的交叠更清楚。
- 仅实际按住时强调缺口两端并加强局部阴影；不改变玉镯尺寸、颜色或透明度，不加选中环。松手、取消和重载后复原。
- 受阻轮廓从每帧344条线段改为首次4条局部路径，此后只更新旋转、透明度与可见性；到期隐藏，复用几何。
- 为消除残影建立当帧索引，避免逐镯遍历残影列表。
- 修复四个音效通道占满时消除声、通关声被直接丢弃的问题：关键结果声替换最早通道，通道数和音量不增加。后台暂停期间拒绝待发音效和转动声。
- 美术与音频素材、平台配置、已确认的混音增益、关卡与判定均保留。

### 已通过

- 本地类型检查、构建、192项单元回归；100关连续旋转完整解法回归通过（约301秒）。
- CI重复通过类型检查、192项单元、100关回归，官方LayaAir 3.4构建成功，产物封存53项SHA256。

- 查看同尺度390×844操作前/按住/结算并排图，以及窄屏结算、横屏按住、减少动态结算原图：阴影层次更清楚，缺口未被遮住，没有选中轮廓；原材质、手势方向、布局与真实成绩保留。未把本次图改为已批准基线。
