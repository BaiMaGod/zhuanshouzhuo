# 正式关全宽自适应视口 V0.13.1

此前正式关手镯视口固定在 x=24、w=672（720 逻辑宽），放大后左右出现硬裁切。本次改为 x=0、w=720；渲染裁切和触摸范围一起扩到完整屏幕宽度。

玉盘原图由 710 等比例扩至 752 逻辑宽，并按相同倍率扩展高度，不拉伸玉镯或玉盘。玉盘、手镯、锁扣保持同一个摄像机矩阵；对正式关的拖动边界再按图片实际放大尺寸约束，防止极限平移露出图像矩形边缘。

启动时按设备宽高比设置逻辑高度，移除原来 1180～1600 的固定高度限制，以免 SHOWALL 在部分屏幕上出现左右白边。本改动针对竖屏游戏，横屏专用 UI 尚未设计。

增加第1关、历史54镯关和第100关的全宽触摸、同比例渲染、极限缩放和平移以及坐标往返回归测试。具体 CI 结果以 GitHub Actions 为准。
