## 浏览器验收

使用实际 Laya/WebGL 运行包及 Playwright，不用引擎替身代替浏览器验收。

1. **完整正式关流程**：360×640、390×844、1280×720均通过。实际鼠标拖动通关正式第1关、进入下一关、返回后继续当前关、图谱导航、第45关/第100关加载、提示后实际拖动消除、提示次数限制、重开、放大和全盘复位。没有页面错误或HTTP资源错误。
2. **真实触控事件**：360×640、390×844均通过。通过浏览器CDP发送 touchStart/touchMove/touchEnd/touchCancel，验证双指缩放不计转动、取消清理手势、实际触摸完整通关、尺寸变化后无残留指针。没有页面错误或HTTP资源错误。
3. **按钮画面回归**：首页设置连续开关、正式关首页/重开/音效/玩法/提示/消除按钮像素检查通过。
4. **无浏览器全局变量启动**：测试移除 document、window、location、localStorage、innerWidth/innerHeight、Worker、AudioContext，保留引擎替身，验证游戏仍能新增场景并使用引擎存储。此项只是运行接口契约检查，不代替小游戏真机测试。
5. **旧预览验收兼容**：可选 Web 调试桥保留只读 canvas 获取入口；游戏输入和启动均不依赖它。该兼容入口另经独立测试。

测试脚本：`tests/browser-campaign.mjs`、`tests/browser-input.mjs`、`tests/browser-buttons.mjs`、`tests/platform.test.mjs`。前两个脚本可通过 `JADE_DIST=.release-out/web` 指向官方导出包；`JADE_REPORT` 可指定报告目录。

高关卡测试为检查旧存档读取，使用预置已通关记录定位高关卡；正式第1关通关及第100关提示后的消除均通过真实输入完成，不直接修改旋转状态来假装通关。
