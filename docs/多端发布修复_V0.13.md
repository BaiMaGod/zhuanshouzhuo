# 多端发布修复 V0.13

本次修复以 LayaAir 3.4.0 的统一接口和官方发布器为准，保留规则、美术、关卡、提示图和既有存档。发布包导出与平台运行验收是两个独立结果。

## 工程与入口

- `laya/JadeBracelet.laya` 是官方工程，`laya/assets/Scene.ls` 挂载 `laya/src/Main.ts`，由它启动实际游戏。
- `npm run laya:prepare` 编译共享源代码，把游戏模块接入官方工程，并准备当前版本实际使用的素材。生成目录已忽略，避免维护第二份游戏代码。
- 独立 Web 入口保留 `public/index.html`。HTML 加载页与调试桥只放在可选 Web 外壳中；没有 DOM 时不影响游戏启动。
- 官方工程启用 `assets` 普通分包、启动自动加载。图片保留原始清晰度，原始旧版美术及录音源文件仍留在源码库，不进入运行包。

## 运行接口

| 功能 | 修复后 |
| --- | --- |
| 单指、鼠标、双指 | `Laya.stage` 事件与 `touchId`、舞台坐标；不再操作 DOM Canvas 或 Pointer Capture |
| 触摸取消 | 引擎规范化的取消事件释放手势，不执行消除道具 |
| 滚轮、键盘 | Laya 鼠标滚轮及键盘事件 |
| 存档 | `Laya.LocalStorage`，保留 `jade-bracelet-laya-v1` 及局内存档键、版本、数据迁移 |
| 前后台 | 引擎 BLUR、VISIBILITY_CHANGE；释放手势、取消异步提示、保存局内进度、停止声音 |
| 尺寸变化 | 引擎初始化后读取 Browser 尺寸，SHOWALL 保持坐标映射；RESIZE 结束正在进行的手势 |
| 音频 | `Laya.SoundManager` / `SoundChannel`，摩擦随转速改变音量和播放速率，短淡出，碰撞去重及四声道上限 |
| 合成音效 | 原合成公式离线生成 PCM WAV，原录音滤波和循环接缝处理离线完成 |
| 字体 | 引擎 Loader 加载 woff，使用文件名对应字体族；不依赖网页 CSS 字体就绪事件 |
| 正式关提示 | 保留预生成依赖图与动作阶段数据，直接查询 |
| 教学关搜索 | 同一碰撞规则下的分帧 DFS，每帧最多12步并检查3ms预算，最多600个搜索节点及20秒；可取消，不依赖 Web Worker |

分帧预算在每个求解操作之间检查，不承诺一次几何操作绝不超过3ms。不同平台音频适配器的实际音质与速率行为仍需设备试听。

## 构建命令

安装官方 CLI 3.4.0 后，在仓库根目录执行：

```bash
npm ci
npm run typecheck
npm test
npm run release:web
npm run release:wechat
npm run release:douyin
npm run release:android
npm run release:ios
```

输出分别位于 `.release-out/web`、`wxgame`、`bytedancegame`、`android`、`ios`。

`LAYAAIR_CLI` 可指定 CLI 可执行文件路径。普通游戏开发仍可用 `npm run build` 输出 `dist`，无需安装完整发布工具。

构建脚本检查官方 `Build end, result=Success` 日志和实际文件。不能只信 CLI 退出码；CLI 下载依赖失败时可能仍退出0。每次清理本目标旧输出，关键文件缺失即失败；小游戏必须包含官方 assets 分包且主包不超过4 MiB。通过后生成 SHA256 清单，浏览器与真机验收字段初始均为 false。

## 验收范围与限制

验证记录见 `docs/多端发布验证_V0.13.md`，以实际结果为准。

- Web 浏览器测试不能代替微信／抖音开发者工具或 Android／iOS 真机测试。
- 不自动上传小游戏或提交应用商店审核。平台 AppID、原生应用标识、签名、图标与商店配置需要发布主体提供；不写入猜测值。
- Android/iOS 必须安装官方 SDK/支持包；iOS 后续编译签名还需 macOS/Xcode 和证书。
- 异形屏安全区、真实后台恢复、手机音频试听与长时间性能属于设备验收项，本次不宣称已完成。
- 不提供跨端云存档；相同存档格式可以复用，各平台本地存储相互独立。
