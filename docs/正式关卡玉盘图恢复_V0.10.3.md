# 正式关卡玉盘可见性修复 V0.10.3

## 问题
V0.10.1 加入首页同款桃花团扇图片时，把它插入了带 `cacheAs='bitmap'` 的游戏场景中。虽然之前也设置了子节点 `zOrder=-2`、玉盘相机 `zOrder=-1`，但该图层组合没有足够隔离，玩家反馈原玉盘图未正常显示。

## 改动
- 完整保留并继续使用 `public/assets/art-rose/tray.png` 原珍珠白淡粉玉盘，不改其尺寸、透明度、材质或 54 镯位置。
- 装饰壁纸 `art-rose/home-bg.jpg` 从 `scene` 子节点移到外层 `root`，设置 `zOrder=-10`；交互场景 `scene` 保持 `zOrder=0`。
- 玉盘留在游戏场景内 `board-backdrop`，随 `Board.applyView()` 相机与手镯一起缩放、平移，背景插画则固定不动。
- 场景切换前销毁外层壁纸，防止重开、教学、返回首页后叠图或残留。
- 补充回归断言：壁纸在根层；玉盘 sprite 存在且绘制原 PNG；玉盘属于独立相机、变焦后仍同步；重开只有一张玉盘；教学场景不遗留正式关背景。

## 验收
先通过 TypeScript、Node 场景/规则回归及官方 LayaAir 3.4 构建，再执行桌面、手机、窄屏浏览器完整路线与线上 smoke。图层检查不等于真机显示检查，最终效果仍应参考实际试玩画面。
