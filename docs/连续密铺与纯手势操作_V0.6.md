# V0.6 连续密铺与纯手势操作

## 最终改动

54只玉镯占满连续的9×6交错格阵列，画面统一旋转成6列9排的竖向密阵。没有空置的内部格位，也没有把九组机关隔开放置的空带。环体外径仍为92世界单位，相邻中心间距92.0001，外缘贴合；0.0001仅用于避免浮点误差造成重叠，不产生可见间隙。含环体外径的包围面积为428585.65，比V0.5.10的900001.2减少52.38%。

仍为54镯、53根所属杆和9根背景固定杆。九处双镯保持机关与接力锁扣组成一个相连结构，完整验证路线为54次合法转动，不宣称最少步数。环体大小、缺口、套扣、0.25°连续碰撞步进及脱扣规则没有调整。转动仍受套扣、邻镯和残留杆碰撞约束。

所有关卡移除旋转、微调、演示、撤销按钮和左右方向键转动；教学十关保留关卡和引导，提示只标出扣位，由玩家自行拖转。正式关保留缩放、全盘、重开和返回。原来在“移动棋盘”和“旋转手镯”之间切换的按钮也已移除。

手镯选中后不绘制圆圈、环绕轨迹线或方向圆点；选中状态通过原有编号与顶部状态显示。教学引导保留手势示意，目标扣使用角标；提示扣使用菱形标记，不画环绕手镯的圆线。

用手指或鼠标拖动实际环体旋转；双指同时缩放和平移，空白处可以单指移动棋盘，电脑支持滚轮缩放。第二根手指加入后停止旋转手势；抬起一指后也不会误转手镯。玉盘、花园、玉镯和锁杆继续共用棋盘变换，缩放和平移不改变锁扣规则。
