# 古风女性向视觉整改 V0.10.0

依据用户确认的桃花、团扇、藕粉古风方案实现，范围为呈现与反馈，不改玩法、关卡难度、碰撞。

## 视觉规范

| 用途 | 色值 |
| --- | --- |
| 外层纯色 / 暖白 | #FCF7F3 |
| 标题 / 主文字 | #684853 |
| 辅助文字 | #927881 |
| 主按钮 / 豆沙红 | #B9788A |
| 次按钮 / 浅藕粉 | #F0DCE1 |
| 细边框 | #C797A3 |
| 面板白 | #FFFAF7 |

- 首页与关卡图谱以桃花、团扇和少量花瓣点缀边缘。正式和教学游戏页使用纯色，不将花枝铺到解谜区域。
- 首页去掉标题投影，设置玉环小印、清雅宋体标题和无底框说明；首次显示开始解镯，有进度显示继续解镯。正式挑战独立开放。
- 控件只使用纯色、细框与简化花窗端角，去掉金属高光、厚影和浮雕。小图标控件保持紧凑圆角。禁用时变淡且不执行动作。
- 按下有轻微缩放和颜色反馈，弹窗淡入；减少动态效果偏好下不执行弹窗淡入。
- 正式页保持首页/重开图标、居中大关卡标题、左右待解/转动计数及底部提示与全盘同行的布局。提示仅展示真实合法方向手指，不替玩家转镯。
- 教学、关卡图谱、设置、玩法、提示和结算使用同一套配色与控件。

## 素材保留与来源

- 保留 `public/assets/jade-v2/` 的全部玉镯、`art-v3/clasp.png` 锁扣、阴影与现有材质音效；不改变材质UV、环体尺寸、缺口或操作几何。
- `art-v3/tray.png` 原图留存；新 `art-rose/tray.png` 为 ImageGen 基于原图的配色编辑，保留外轮廓、边缘位置和透明通道，金黄改成珍珠白与淡粉。正式盘面继续使用原有保守椭圆安全区，不重新生成关卡。
- `art-rose/home-bg.jpg` 为 ImageGen 新绘桃花团扇背景，中心留白，不烘入文字与按钮；JPEG质量91用于控制加载体积。首页不新增逐帧花瓣粒子。
- 标题和按钮用精简 Noto Serif SC，数值与说明用精简 Noto Sans CJK SC；字体由页面本地加载，绘制前等待就绪，合计约192 KiB。来源为 Google Fonts / Noto，许可证随包 `assets/fonts/OFL.txt`。字体仅包含当前界面字库；新增文案需同步补字。

## 本轮验证

- 严格TypeScript检查、Web构建、40项现有回归检查通过，包含十个教学关及54镯正式路线、锁杆保留、双指缩放、重开、手指提示与音效生命周期。
- 本地Chromium真实CDP触控验证360×640、390×844、430×932与1280×720横屏SHOWALL：首页进入、设置/静音恢复、教学实际转镯通关与结算、下一关、转动后重开、图谱导航、正式提示不改状态、放大/全盘、玩法关闭、三轮反复导航。无脚本错误、资源失败或HTTP错误。
