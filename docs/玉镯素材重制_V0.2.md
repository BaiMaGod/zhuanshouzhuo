# 玉镯素材重制 V0.2

日期：2026-10-12。目标参考：用户提供的第二张效果图中亮黄、藕粉及乳白玉石的通透插画质感。

## 本轮明确验收项

- 金黄色玉环采用浅金黄、乳白云纹与长弧形白色亮面，没有上一版连续褐色暗圈。
- 藕粉、青玉、冰青、暖白保持相同顶视方向、细节密度和高光风格。
- 原始 PNG 外部和中心均真实透明，不带棋盘、文字或连接件。
- 原始生成图不做重绘或颜色覆盖。用 LayaAir 原生 drawTriangles 映射纹理；环体半径、环宽和缺口来自当前规则模块。
- 生成图片的圆心及边缘由只读 alpha 测量记录；五种材质映射到相同环体，不引入扣位偏移。
- 游戏现有规则、关卡、输入、碰撞、状态和消除归属不变。
- 进行中、结算、重开及至少一次桌面/触摸真实输入在最终构建上通过。
- 对照实际截图与目标图审查浅金色、乳白透光、细云纹、弧形亮面和柔和投影，不宣称两张不同布局的图片逐像素一致。

## 保留与替换

保留 core、levels、model、存档、音效、提示、拖动及已有玉盘/植物背景。上一版 public/assets/amber.png 等文件仍保留，运行时已停止引用其程序材质。

新素材在 public/assets/jade-v2/，每张 1254×1254，包含 amber、peach、celadon、ice、ivory。它们均通过内置 ImageGen 生成；原始生成 PNG 保持不变，包含真实透明通道。生成前使用用户效果图作为风格参考，不复制其人物、商业标题和布局。

锁杆轮廓和几何保持原尺寸。仅调整颜色、高光及固定座内的玉石小圆面；不会新增连线、移动扣体、删除残留杆件或扩大缺口。

## 提示词规格

共用规格：单只闭合 O 形玉镯，严格顶视、正圆、均匀圆润环体；浅色半透明玉石、乳白云纹、弧形白色高光、左上柔光；外部及中心透明；没有背景、投影、文字、锁扣或其他对象。闭环提供完整纹理，由引擎生成真实玩法细缺口。

各色补充：amber 为浅金黄/蜜黄；peach 为浅藕粉/奶白桃粉；celadon 为浅青玉/乳白薄荷绿；ice 为浅冰青/淡蓝绿；ivory 为暖白/浅奶油黄。后四张使用金黄生成图作为几何及风格一致性参考。所有图避免褐色脏斑、黑色内倒角、金属、硬塑料与写实摄影风。

类型检查、既有规则及控制器回归、素材网格几何检查与实际浏览器截图复核在本轮最终代码上记录。手机真机长时间性能与实际试听另行验证，不以浏览器模拟替代真机。相关音效及机制文件本轮未修改。
