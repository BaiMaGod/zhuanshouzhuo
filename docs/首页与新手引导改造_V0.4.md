# 玉环十境：首页与新手引导 V0.4

## 目标与玩家流程

进入游戏先看到玉盘上的真实双镯连接、大标题和唯一主要动作「开始解镯」。已通关玩家看到「继续解镯」，首页同时展示已解关数、星级、即将进入的关卡。「关卡图谱」和「新手练习」为次级入口，设置放在右上角。

第一关直接进入可操作盘面，不先弹整段规则。教学仅说明当前动作：找到粉色 B 镯 → 拖动缺口对准空心扣 → 实际消除与结算。金色圈标出目标扣位，手势沿环体示意拖动，装饰层不接收触摸、不改真实角度。选错镯时提示先试 B，玩家仍可自由操作。跳过按钮随时可用；首页练习和玩法里的「重看这一步」可以重新学习。

第二关首次说明背景固定杆两端要分别对齐；第三关首次说明邻镯消失后，所属镯的完整杆仍然存在。逐步介绍机制，无计时压力、不惩罚试错。完成或跳过的教学写入原存档新增的 tutorial 字段，保留 version=1、进度、星级及声音设置，旧存档自动兼容。

## 视觉与输入

- 保留已有五张玉镯纹理、盘面、背景、锁扣和摩擦/碰撞音效。
- 首页不再用大矩形标题卡；用带金色偏移阴影的标题、玉盘真实连接预览、轻量金色微光。
- 共享按钮采用多层雕边、上下高光、底部立体阴影、统一引擎绘制图标。按下移动表现层4单位，松开和移出恢复；触摸判定框不变。
- 图谱显示当前境、三星/未获星、锁定状态；当前境以深青玉按钮突出。
- 结算使用三星展示与明确下一境/重试动作；玩法以三条简短说明展开。
- LayaAir Graphics.drawPath 未支持二次曲线命令，图标/手势的二次曲线先采样为线段，避免部分形状丢失。

## 保持的规则

缺口、碰撞、锁杆归属、连续旋转、重新扣合、消除条件、关卡布局、合法演示、计分规则均沿用 V3.2。不用引导修改角度、自动解锁或扩大判定。
