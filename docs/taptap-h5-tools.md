# TapTap H5 道具与排行榜（0.15.5）

- 首页入口为“排行榜”，只提供关卡榜和星数榜；云档仍在后台自动恢复和同步。
- 正式关卡初始免费提示 1 次、免费消除 0 次。旧盘面保留已获得的激励奖励，不再恢复旧版免费消除。
- 道具按钮只显示名称与次数。用完后弹窗提供“看视频得道具”“分享得道具”。每种道具的视频、分享分别每关限领 1 次；重开重置，返回、刷新和云档合并不重置。
- 分享仅在 tap.onShareMessage 的 success 事件后发奖。拉起分享面板、取消、失败或超时不发奖，旧盘面回调不会影响新盘面。
- 消除选镯提示使用 30 号字的信息框，放在底部按钮上方，触摸可穿透到盘面。

## 发布前配置

config/taptap-public.json 的 shareTemplateId 必须填入应用 958691 已审核通过的分享模板 template_code，也可由 TAP_SHARE_TEMPLATE_ID 注入。它不是广告位 ID。

默认分享模板已恢复为历史 H5 包使用的 `ST1792455066861BCSTD2Y3D`（2026-10-28 从此前发布记录恢复）。此前默认配置为空，不代表后台不存在已审核模板。发布仍运行 release:taptap、verify:taptap，并在 TapTap 宿主内复测成功分享与取消分享；本地模拟测试不能替代真实渠道验收。
