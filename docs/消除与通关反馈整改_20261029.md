# 消除与通关反馈整改

## 修改前接受条件

- 保留玉镯原贴图、玉盘、桃花背景、音乐与音量配置；不改关卡、旋转、碰撞、吸附、提示/消除道具、星级计分。
- 单次消除：实际扣位短暂翠绿亮光，玉镯先轻抬再消散，有限量的玉光碎片；特效不截获输入，不盖住相邻手镯。
- 连续消除：仅按真实消除事件调整装饰强度，最多三档；不新增连击奖励、计分或额外消除。
- 最后清盘：玉盘局部柔光和花瓣收束，约半秒庆祝后进入结算；一局仅触发一次。
- 专用通关面板：逐颗点亮实际获得的星星、显示真实手镯数与步数、主按钮突出。下一关、重玩、回首页可用，退出和重开无残留。
- 支持系统减少动态效果；装饰粒子最多128个、消除残影最多32个，复用效果容器，避免逐帧创建节点。
- 窄屏360×640、长屏390×844和横屏1280×720布局可用；真实拖动完成正式第一关并验证下一关和重玩。
- 运行类型检查、全量已有单元测试和相关浏览器回归，记录异常与截图。性能采用浏览器帧间隔代理，目标p95≤33.3ms；浏览器模拟不等于真机验证。
