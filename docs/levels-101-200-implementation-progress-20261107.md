## 七关样板仍不能进正式关卡

设计骨架中107、131、151、161、171、191、200共7关缺少数百条活动扣 Receiver、所有真实几何点/路径以及同引擎全盘合法通关回放。保留原稿为空，不用伪造直线、虚假邻接或一键清空来凑数。**编译器明确拒绝缺失的字段，避免将未验证的设计当成可玩关卡。**

当前还没有将它们插入`src/formal-campaign.js`或导出至`src/levels.js`。因此现有正式关卡仍是1–100，TapTap原包仍是0.15.16；任何构建产物只用于开发CI，不属于新的游戏发布包。

5. 修复新模块所有CI失败并核对前100关测试；视觉与触控验收独立于自动化技术测试。
