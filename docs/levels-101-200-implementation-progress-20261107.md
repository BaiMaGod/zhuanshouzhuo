## 2026-11-08 第107关几何复用试验：已否决

本轮曾尝试以现有第100关109镯盘面为底图，删除一件背景扣，再补8根自带扣以匹配第107关聚合配额。该方案与权威样板的R001/R002爆裂接续和真实连接关系不符，不能代表正式第107关配置，现已从运行时和CI中移除。原先被误标为无法追溯的第107关109条逐镯记录及14件背景扣记录，已逐行与原始工作簿核对，规范化字段哈希一致，并改名为`docs/levels-101-200-level107-source.json`。

否决依据：

1. 第107关正式样板要求以R001/R002作为双爆裂接续，并按权威部分源数据配置F001–F014端点。试验盘面使用了另一组爆裂镯和自造Owner→Receiver关系，与样板关键结构不一致。
2. 单根锁扣的接收端消除后，Owner尚存时杆体仍然存在并继续参与碰撞。只验证Receiver释放、没有回放到Owner消除，会漏掉后续阻挡。
3. 全路线物理筛选中，多个候选杆件在后续动作挡住其他镯子；例如R63→R6会挡住R1开局旋转，R30→R1会在后续挡住R16。对候选Owner逐一完整回放后，没有找到4个Owner各自拥有2根全路线无碰撞锁扣的组合。试验组合最终未通过物理回放。

清理结果：

- 删除临时的src/level107-sample.js及其单测、几何分析测试、浏览器样板测试和专用分析Workflow。
- 从src/main.ts移除?sample107=1调试入口、样板关卡索引及样板通关分支。
- 从主CI移除依赖该临时样板路线的浏览器验收与报告上传步骤。
- 不修改第1–100关正式数据，不把任何临时样板加入formal-campaign.js或levels.js。

**下一步不是继续给第100关追加锁扣，而是按权威第107关源数据制作独立样板：**逐镯属性、自带扣配额、缠丝层数、角色、部分关键前置注记，以及F001–F014背景扣目标镯编号均已存在；还需补齐125根自带扣的完整Owner→Receiver边表，落实R001/R002爆裂接续及真实相邻关系，再制作玉盘坐标、活动杆端点和背景支杆路径。随后用advanced-level-compiler.js和verify-advanced-samples.mjs做全路线物理回放，最后独立进行浏览器/手机验收。
