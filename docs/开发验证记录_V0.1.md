# 玉环十境 V0.1 开发与验证记录

日期：2026-10-12。基准：仓库 V3.2 文档及用户确认通过的 10 关 HTML 原型。

## 本轮交付

新增 LayaAir 3.4.0 正式游戏工程、由简到难的十关、逐关解锁、本地存档、撤销、重开、合法吸附、目标提示、整关演示、星级结算和音效。美术使用五种玉石曲面材质、瓷质玉盘和植物背景。玩法与画面共用原型的 R=40、环宽=12、缺口净宽=9、套扣宽=7。

## 已完成检查

`npm test`：22 项通过，0 项失败，包含严格 TypeScript 构建。

| 范围 | 结果与证据 |
| --- | --- |
| 10 关布局 | 环体不重叠、端点贴合真实环边、无开局零连接清场 |
| 10 关连续完整路线 | 按最多 2.4° 的逐次请求重放验证路线，所有玉环清空 |
| 手动/演示入口一致 | 大请求与 1° 请求产生相同消除及端状态；均使用 core.request |
| owner / receiver | receiver 旋转不带动杆件；owner 请求大角度时受环体约束停止 |
| aligned 的实体限制 | aligned 不允许 owner 强转扣体离开现存 receiver |
| 背景杆独立两端 | 一端消除不删除另一端及本体 |
| 残留杆 | 三镯首个 receiver 消除后 owner 的完整杆仍在，合法旋转保持杆长 |
| 保持与重新扣合 | 单端对齐且另有连接时不提前消除，转离重新扣合 |
| 跨零度 | 359° 到 1° 连续请求正确 |
| 撤销 | 全部姿态、生命周期、端状态、计数恢复 |
| 存档 | 逐关解锁，刷新恢复，异常 JSON 回退初始状态 |
| 指针控制器 | 点击只选中、沿可见玉环路径拖动通关、取消后释放捕获 |
| 演示控制器 | 逐帧经过正常入口，淡出完成后结算并开启下一关 |
| 视图与输入 | 10 关的视图变换与输入坐标互逆 |

连接几何保留原型中的 0.025 径向公差，部分 owner 在遇阻前可产生小于 1° 的微小位移。检查验证其仍在公差内并停止，不把“不得自由强转”错误实现为所有请求必须严格为 0°。

关卡验证路线动作数分别为：1、2、2、3、6、5、9、11、10、11。这是已验证路线长度，不宣称已证明最优解，也不等同于经过玩家研究的难度曲线。

## 验证限制

已检查材质透明通道、完整环体/缺口图像和场景绘制命令的静态布局。场景控制器检查通过 Node 替身执行；没有以此声称实际浏览器或 WebGL 试玩通过。

当前环境没有可用的受支持浏览器控制能力。未完成实际 Laya WebGL 渲染、手机 Safari/Firefox/Chrome 长时间触控及真机性能检查。部署成功只证明构建包被成功发布，不替代上述试玩验收。

## 后续验收重点

实际手机确认细缺口和完整空心扣清晰；第 5、8、9、10 关的保持组合在真实拖动下可完成；提示规划中的重开/切后台能及时取消；密集关卡不误选相邻玉环；窄屏及旋转设备后按钮和棋盘保持可用。
