# 高清原图与运行素材

本目录保留优化前的八张 PNG 和原始玉镯轮廓坐标，不参与 Web/H5 或 Laya 发布打包。
首页背景、手指素材保持现状，不另存副本。历史旧美术继续保留在原位置并排除发布。

重新生成：安装 Pillow 9.1+ 后执行 `npm run images:optimize`。
脚本始终读取本目录高清原图，避免重复压缩，并同步更新 `src/jade-profiles.js`。
五种玉镯保持整张画布，中心、内外半径和图像尺寸同比例缩放，归一化 UV 不变。
锁扣和阴影保持透明背景与原有定位，不裁切。玉盘保持 1122×1402 和原始 RGBA 像素，仅优化 PNG 编码。

`npm run images:audit` 检查 10 张运行图片的尺寸和总量（上限 3 MiB），单张超过 500 KiB 会提示复核。
玉盘是已检查的全分辨率例外。普通构建不依赖 Pillow，直接使用已提交的优化 PNG。
