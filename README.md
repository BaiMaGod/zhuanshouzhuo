# 转手镯消除 · 玉环十境

LayaAir 3.4.0 的首版关卡游戏。规则采用已确认的 V3.2 设计文档及通过验收的十关 HTML 原型；环体几何、两类锁杆、重新扣合、归属消除及连续碰撞入口沿用同一规则模块。

## 当前内容

- 首页、十境图谱、由简到难的 10 关、逐关解锁和星级结算。
- 拖动玉环，点击只选中；1° 微调、30° 转动、近扣位合法吸附。
- 撤销、重开、目标提示、对准一扣及整关演示；演示也经过正常旋转求解入口。
- 琥珀黄、藕粉、青玉、冰青和暖白五种玉石材质；完整空心套扣、实心座、背景锚点、释放淡出和音效。
- 浏览器本地保存通关进度、最好步数、星级与音效开关，无账号及网络存档。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm test
npm run build
npx http-server dist -p 8080
```

访问 `http://localhost:8080`。部署只需要 `dist/` 内容，服务器必须正确提供 JavaScript 模块的 MIME 类型。不能直接双击 HTML 以 file:// 打开。

美术素材已经预生成，无需 Python 即可构建。重新生成可执行 `npm run art`，需要 Python 3、NumPy 和 Pillow。

| src/ui.ts | Laya UI 基础组件 |

| tests/rules.test.mjs | 规则、连续通关和保存检查 |

业务场景采用严格 TypeScript。迁入的规则与关卡模块保留 JavaScript，以保留通过版本；TypeScript 编译器统一复制到构建输出。引擎运行库已经随工程提供，不依赖运行时 CDN。

## 规则边界

手镯所属杆的固定座和完整杆件随 owner 的合法旋转变化，只随 owner 消除。receiver 消除时连接失效，尚存 owner 的完整杆件仍参与碰撞。背景杆保持固定，两个空心端分别判定，并在全部玉环消除后保留。对齐状态按当前几何计算，转离重新扣合，不能永久累计。

视图在细长屏幕上可以整体旋转或缩放以适应棋盘，所有环、缺口、杆件一起变换；关卡的世界几何和操作规则不因此改变。

星级按转动次数评估：不超过验证路线次数 +2 为三星，+6 内为二星，其他为一星。拖动手势记一次转动，按钮每次记一次，完整演示每个动作记一次。没有时间限制，也没有永久扣除提示次数。
