# 转手镯消除 · 玉环十境

LayaAir 3.4.0关卡游戏。V0.6.0将54镯正式挑战「九宫锁玉阵」改为连续占满的竖向密阵，相邻镯外缘贴合，中央没有空置格位。保留62根锁杆和9处双镯保持机关，真实环体大小、缺口和碰撞规则不变。所有关卡移除旋转、微调、演示和撤销按钮，只能直接拖动玉镯旋转；选中时没有圆圈描边。双指缩放和平移、滚轮缩放、全盘复位与背景同步变换保留。规则采用已确认的V3.2设计文档；归属消除、重新扣合和连续碰撞沿用同一规则模块。

## 当前内容

- 首页独立54镯正式挑战；教学十关、逐关解锁与独立成绩。
- 拖动玉环，点击只选中，不画圆圈线；正式关双指/滚轮缩放、双指/空白平移与全盘复位。
- 保留重开；教学提示只标出扣位，玩家自行用手指拖转，没有按钮代转或撤销。
- 琥珀黄、藕粉、青玉、冰青和暖白五种玉石材质；完整空心套扣、实心座、背景锚点、释放淡出和音效。
- 浏览器本地保存通关进度、最好步数、星级与音效开关，无账号及网络存档。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm test
npm run build
npx http-server dist -p 8080
```

访问 `http://localhost:8080`。部署只需要 `dist/` 内容，服务器必须正确提供 JavaScript 模块的 MIME 类型。不能直接双击 HTML 以 file:// 打开。

美术素材已经预生成，无需 Python 即可构建。V0.2 的生成 PNG 保存在 public/assets/jade-v2/，提示词与替换记录见 docs/玉镯素材重制_V0.2.md。scripts/measure-jade.py 只读取透明通道并记录纹理坐标，不改写图片。npm run art 仅用于保留的 V0.1 旧程序素材，运行界面已不再引用旧玉镯贴图。

## 规则边界

手镯所属杆的固定座和完整杆件随 owner 的合法旋转变化，只随 owner 消除。receiver 消除时连接失效，尚存 owner 的完整杆件仍参与碰撞。背景杆保持固定，两个空心端分别判定，并在全部玉环消除后保留。对齐状态按当前几何计算，转离重新扣合，不能永久累计。

视图在细长屏幕上可以整体旋转或缩放以适应棋盘，玉盘、花园背景以及所有环、缺口、杆件一起变换；关卡的世界几何和操作规则不因此改变。

星级按转动次数评估：不超过验证路线次数 +2 为三星，+6 内为二星，其他为一星。一次真实拖动手势记一次转动。没有时间限制，也没有永久扣除提示次数。
