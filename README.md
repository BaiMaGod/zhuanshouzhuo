# 转手镯消除 · 玉环十境

LayaAir 3.4.0 关卡游戏。V0.5.5 新增独立正式挑战「九宫锁玉阵」：54只手镯、62根锁杆、九宫跨区拆解，支持双指缩放、滚轮缩放、拖动画面及一键全盘。原10关保留为教学关，教学微调/提示/演示按钮保留。正式关只提供旋转、撤销、重开与视图操作。V0.4.1 已上线游戏首页、玉石雕边按钮及盘面分步引导，并缓存静态界面降低渲染成本。此前 V0.2 已换用五张独立 ImageGen 玉镯素材，采用原生纹理网格贴合真实环体与细缺口。规则采用已确认的 V3.2 设计文档及通过验收的十关 HTML 原型；环体几何、两类锁杆、重新扣合、归属消除及连续碰撞入口沿用同一规则模块。

## 当前内容

- 首页独立54镯正式挑战；教学十关、逐关解锁与独立成绩。
- 拖动玉环，点击只选中；双指/滚轮缩放、平移与全盘复位；教学保留1°微调和30°转动。
- 撤销保留视角、重开；教学保留目标提示、对准一扣及整关演示，演示经过正常旋转求解入口。
- 琥珀黄、藕粉、青玉、冰青和暖白五种玉石材质；完整空心套扣、实心座、背景锚点、释放淡出和音效。
- 浏览器本地保存通关进度、最好步数、星级与音效开关，无账号及网络存档。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm test
npm run build
npx http-server dist -p 8080
```

访问 `http://localhost:8080`。部署只需要 `dist/` 内容，服务器必须正确提供 JavaScript 模块的 MIME 类型。不能直接双击 HTML 以 file:// 打开。

美术素材已经预生成，无需 Python 即可构建。V0.2 的生成 PNG 保存在 public/assets/jade-v2/，提示词与替换记录见 docs/玉镯素材重制_V0.2.md。scripts/measure-jade.py 只读取透明通道并记录纹理坐标，不改写图片。npm run art 仅用于保留的 V0.1 旧程序素材，运行界面已不再引用旧玉镯贴图。

## 规则边界

手镯所属杆的固定座和完整杆件随 owner 的合法旋转变化，只随 owner 消除。receiver 消除时连接失效，尚存 owner 的完整杆件仍参与碰撞。背景杆保持固定，两个空心端分别判定，并在全部玉环消除后保留。对齐状态按当前几何计算，转离重新扣合，不能永久累计。

视图在细长屏幕上可以整体旋转或缩放以适应棋盘，所有环、缺口、杆件一起变换；关卡的世界几何和操作规则不因此改变。

星级按转动次数评估：不超过验证路线次数 +2 为三星，+6 内为二星，其他为一星。拖动手势记一次转动，按钮每次记一次，完整演示每个动作记一次。没有时间限制，也没有永久扣除提示次数。
